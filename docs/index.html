Юу хийж чадах вэ

Дискийг зөвхөн уншдаг тул таны өгөгдлийг хэзээ ч өөрчлөхгүй.

Хурдан скан

NTFS, FAT12/16/32, exFAT дээр устгагдсан файлыг нэр, хавтас, огноотой нь олно.

Гүн скан

Format хийсэн, хуваалт нь устсан дискнээс 25+ төрлийн файлыг signature-ээр хайна.

Урьдчилан харах

Зураг, текст, hex-ийг сэргээхээс өмнө нь харж шалгана.

Чанарын үнэлгээ

Файл бүрийг “Сайн / Тодорхойгүй / Гэмтсэн” гэж ангилж харуулна.

Бүх төрлийн диск

HDD, SSD, USB flash, SD карт, MBR/GPT физик диск, .img/.dd image.

Хэсэгчилсэн файл

NTFS data run, exFAT FAT chain-аар хэсэг хэсэгт хуваагдсан файлыг бүрэн угсарна.

Татаж авах

Хамгийн сүүлийн хувилбар

Санал болгох

Installer (.exe)

Суулгаад Start цэснээс ажиллуулна.
 

MSI багц

Байгууллагад олноор суулгахад тохиромжтой.
 

Командын мөр (CLI)

Суулгах шаардлагагүй ганц metarecover.exe.

Хэрхэн ашиглах

  1. Installer-ыг татаж ажиллуулна. Windows “unknown publisher” гэж анхааруулбал More info → Run anyway дарна.
  2. Програм нээгдэхэд Administrator эрх асууна — дискийг шууд уншихад шаардлагатай.
  3. Файл устсан дискээ сонгоод Хурдан скан эхлүүлнэ. Олдохгүй бол Гүн скан хийнэ.
  4. Сэргээх файлаа сонгоод өөр диск рүү хадгална.
Анхаар: файл устсаны дараа тэр диск рүү юу ч бүү хуулж, бүү суулга — шинэ өгөгдөл хуучныг дарж бичнэ. SSD (TRIM) дээр устгасан файл ихэнхдээ бүрмөсөн арилдаг тул HDD, USB, SD карт дээр сэргээлт хамгийн сайн ажиллана.
